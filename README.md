# GNN + LLM for Heterogeneous Graph Reasoning

## 📖 Description
This project explores the fusion of **Graph Neural Networks (GNNs)** and **Large Language Models (LLMs)**
to enable **reasoning, explanation, and link prediction** over **heterogeneous graphs**.

The system combines:
- Structural learning with heterogeneous GNNs
- Subgraph extraction and reasoning paths
- LLM-based explanation generation (via Ollama)

This repository contains the **codebase only** (no datasets, no LaTeX report).
